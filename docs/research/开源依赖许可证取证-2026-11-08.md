## 二、两个专项传递结论

### 2.1 shadcn copy-in 许可传递（S-9 判据核心）

**已证实事实**：shadcn-ui/ui 仓库 LICENSE.md 为标准 MIT（Copyright (c) 2023 shadcn）[3]；官方组件源码文件不带版权头（button.tsx 以 `import` 直接开头，仓库原文实证）[3]；官方 FAQ 原文："Can I use this in my project?" → **"Yes. Free to use for personal and commercial projects. No attribution required."**（ui.shadcn.com/docs/components/base/collapsible，2026-11-08）[4]。

**传递结论**：组件源码复制入 `client/src/renderer/ui/` 后成为我方代码的实质性部分——MIT 允许任意修改、再许可、闭源分发，**对 Constella 闭源商业分发无阻断**；字面义务是分发物中保留 shadcn 的版权与许可声明，官方 FAQ 已明示不要求署名，但建议在仓库随附一份 third-party-notices（登记组件来源 + MIT 文本，零成本消除解释分歧）；后续改造衍生的组件同样可闭源。copy-in 的运行时依赖（radix-ui、vaul、sonner、cmdk，均 MIT [1][5]）以 npm 分发，闭源打包仅需保留各自声明。shadcn CLI 本身（npm 包 `shadcn` manifest license 字段为空）系开发期工具，不随产品分发，无传递义务。

### 2.2 better-sqlite3 × SQLite

**已证实事实**：better-sqlite3 13.0.3 LICENSE 原文为纯 MIT（Joshua Wise，无第三方附注段）[7]；仓库 deps/ 含 sqlite3/（SQLite amalgamation 源码）与 download.sh，编译时捆绑 SQLite [7]；SQLite 官网版权页声明其代码为 **Public Domain**（sqlite.org/copyright.html）[10]。

**传递结论**：SQLite 属公有领域而非 OSI 许可证，**无任何保留/开源/付费义务**，编译产物闭源分发零约束；我方唯一义务是随分发物保留 better-sqlite3 本体的 MIT 声明。
